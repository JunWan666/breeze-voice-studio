接入说明

这个试听台同时提供了一个 OpenAI 兼容的语音合成网关，任何支持 OpenAI TTS 的客户端 （openai SDK、LobeChat、Open WebUI、各种朗读插件）都能直接把地址换过来用。 后端仍是 Breeze Blue 官方模型，key 用你自己的，服务器只做转发、不留存。

基础地址

https://voice.example.com/v1

鉴权

把你在 Breeze 后台 创建的 key（brz_ 开头）放进请求头：

Authorization: Bearer brz_你的key

也支持 xi-api-key: brz_... 或 X-BB-Key: brz_...。key 不会被保存到服务器。

方式一：OpenAI 兼容（推荐）

curl https://voice.example.com/v1/audio/speech \
  -H "Authorization: Bearer brz_你的key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "breeze-tts-2",
    "input": "你好，这是一段测试语音。",
    "voice": "voc_rh6e8hdbraz6",
    "response_format": "mp3",
    "speed": 1.0
  }' --output hello.mp3
# Python：直接复用官方 openai 库，只改 base_url
from openai import OpenAI

client = OpenAI(base_url="https://voice.example.com/v1", api_key="brz_你的key")

resp = client.audio.speech.create(
    model="breeze-tts-2",
    voice="voc_rh6e8hdbraz6",
    input="你好，这是一段测试语音。",
    response_format="mp3",
)
open("hello.mp3", "wb").write(resp.read())
// Node.js
import OpenAI from "openai";
import fs from "node:fs";

const client = new OpenAI({ baseURL: "https://voice.example.com/v1", apiKey: "brz_你的key" });
const res = await client.audio.speech.create({
  model: "breeze-tts-2",
  voice: "voc_rh6e8hdbraz6",
  input: "你好，这是一段测试语音。",
  response_format: "mp3",
});
fs.writeFileSync("hello.mp3", Buffer.from(await res.arrayBuffer()));

方式二：直接调 Breeze 官方 API

如果你不需要中转，也可以直接打官方端点（需要 Breeze 的 key）：

curl -X POST "https://api.breeze.blue/v1/text-to-speech/voc_rh6e8hdbraz6?output_format=mp3" \
  -H "xi-api-key: brz_你的key" \
  -H "content-type: application/json" \
  -d '{"text": "你好，这是一段测试语音。", "model_id": "breeze-tts-2", "language_code": "zh"}' \
  --output hello.mp3

注意：官方 API 不允许浏览器跨域直连（没有 CORS 头），网页里调要用本页的方式一。

参数说明

参数必填说明
input是要合成的文字，默认上限 1000 字（本网关放宽到 2000）
voice是Breeze 音色 ID，voc_ 开头；从音色库卡片右下角「复制 ID」获取
model否breeze-tts-2（中/英）或 breeze-tts-2-multilingual（51 种语言）；也接受 tts-1 这类别名
response_format否mp3（默认）、wav、opus、aac、flac、pcm
speed否语速 0.5 ~ 2.0，保持音高不变，默认 1.0
instructions否表演指令，如「用轻快的语气，句尾上扬」，用与文本相同的语言写
language否ISO 639-1 两字母语言码，不传则由模型自动判断

返回与错误

成功时直接返回音频二进制，Content-Type 对应格式，响应头带 X-History-Id。 失败时返回 OpenAI 风格的错误体：

状态码type常见原因
400invalid_request_error缺少 input / voice，或音色 ID 格式不对
401authentication_errorkey 缺失、拼错或已被禁用
402insufficient_quota你 key 名下额度不足
429rate_limit_error请求太密集，或同时生成数量超限，稍后重试

语言代码

breeze-tts-2 支持 zh、en；breeze-tts-2-multilingual 支持 51 种： af ar bg bn bs ca cs da de el en es et eu fa fi fr gl he hi hu id is it ja kn ko lt mr ms ne nl no pl pt ro ru sk sl sq sv sw ta te th tl tr uk ur vi zh。

注意事项

  • 这个网关不存储你的 key：只在单次请求中转发给 Breeze，不写数据库、不写日志。
  • 省钱提示：同一段文本反复请求会重复计费，调试时先用短句。
  • 免费套餐有「同时生成数量」限制，批量合成请控制并发、失败后指数退避重试。
  • 请勿把这个地址当作公共免费接口对外分发；每个人用自己的 key。
